สิ่งที่ต้องทำ (หลังสอบ)
/1.  แก้ตัว inventory.HTML แก้ตรงล็อคอิน เมื่อล็อคอินหน้าmain หน้าอื่นต้องขึ้นเหมือนกันตรงข้อมูลล็อคอิน
2.  หน้า ADD ต้องมีการตรวจสอบว่ารับค่ามามีค่าอันที่มีอยู่ไหมถ้ามีก็ให้เอาไปรวมถ้าไม่มีก็เพิ่มปกติ
/3.  ทำหน้า login เก็บข้อมูลไว้ใน txt 2 อันคือ user / password
/4.  ทำหน้า UI สำหรับแสดงหน้าเริ่มต้นคือ โลโก้บริษัท ชื่อและหน้าตัวรับข้อมมูลในการใส่ข้อมูลล็อคอินถึงจะเข้าได้ ถ้าไม่มีชื่ออีเมล์ในระบบ หรือรหัสไม่ถูกต้องไม่ให้เข้า
/5.  เมื่อล็อเอ้าออกจากเว็บให้กลับไปหน้าล็อคอินเริ่มแรก HOME.HTML
/6.  ทำหน้า setting สามารถแก้เป็นหน้าโทนขาวหรือดำได้โดยเวลาเปลียนให้โทนสีเหมือนกันทุกหน้า
7.  ปรับให้เท่ากับขนาดของจอไอแพด
/8.  ทำหน้า UI ที่แสดงประวัติการทำงานทั้งหมด หน้า UI คล้ายๆ inventory แค่เเสดงใครเพิ่มสินค้าตัวนี้ ใครลบ ใครแก้ เป็นตัวชื่ออีเมลที่จะขึ้น ซึ่งหน้านี้จะเข้าได้แค่คนที่มีรหัสซึ่งไม่เหมือนกับตัวรหัสลบ 
9.  ทำหน้า ใส่รหัสลบให้ดูดีขึ้นโดยเป็นหน้าลอยขึ้นกลางหน้าเพื่อใส่รหัสลบ และเป็นไอดีสิ้นค่ากับรายละเอียดแต่ไม่สามารถพิมแก้ได้แค่โชว์ให้ดู
10. ทำหน้า edit ให้ลอยอยู่กลางจอหน้า inventory แล้วก็ข้อมูลรายละเอียดของของที่กด edit แล้วสามารถพิมพ์แก้ได้เลย
